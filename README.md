# hxwl-12 心理咨询个案记录

临床假设证据台：个案概念化从会前笔记搬进个案页，假设、证据、版本全程留痕。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5112

## 功能

- **当前假设常驻个案页**：每个个案保留当前假设与判断依据（版本化）
- **会谈后证据登记**：支持事实 / 相反事实分别登记，署名归档、只增不改
- **修订触发**：当前版本的相反事实累计 2 条时，原假设不能直接确认，须填清修订原因另存为新版本；旧版本与证据链保留在版本历史可查
- **个案转介**：转介后接手人只能追加证据与版本，不能改写前任记录（界面不提供任何修改 / 删除入口）
- **重开一致性**：数据保存在 localStorage，重新打开时自动校正当前版本指针与证据链，保证当前假设、证据链、版本三者对齐

## 演示数据

- `C-042 焦虑`：已有 1 条相反事实，再登记 1 条即可触发修订流程
- `C-203 职业压力`：相反事实已满 2 条，处于待修订状态
- `C-119 亲密关系`：已完成一次转介（林岚 → 周航）与一次假设修订，可查看历史版本与前任记录

切换左侧「当前用户」可体验负责人权限：仅当前负责人可登记证据、修订、确认与转介。
