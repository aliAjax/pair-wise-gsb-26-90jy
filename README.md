# hxwl-12 心理咨询个案记录

临床假设证据台：个案概念化不再只躺在会前笔记里，而是在线维护「假设 — 证据 — 版本」链条，判断如何变化全程可追踪。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5112

## 核心规则

- **当前假设 + 判断依据**：每个个案始终有一个当前假设版本，附判断依据。
- **会谈后登记事实**：支持事实与相反事实分列登记，只增不改，自动挂到登记时的当前版本名下。
- **两条相反事实冻结确认**：当前版本的相反事实累计到 2 条时，「确认假设」被禁用，必须填写修订原因后另存为新版本；旧版本与其证据链永久保留、随时回查。
- **转介只读**：个案转介后负责人变更，接手人只能追加证据与版本，前任留下的假设、证据、转介记录全部只读（系统不提供任何修改/删除历史记录的入口）。
- **重开一致性**：数据持久化在 localStorage，每次加载后自动核对——版本号连续、每条证据都指向存在的版本、转介链与当前负责人对齐，核对结果显示在个案页头部。

## 操作说明

- 左侧切换个案与「当前操作人」；仅当前负责人可登记证据、确认、修订或转介，其他人只读。
- 种子数据演示三种状态：C-042（验证中，1 条相反事实）、C-203（相反事实达 2 条，待修订）、C-119（已转介 + 已修订，含前任只读记录）。

## 目录

- `src/types.ts` — 领域模型（假设版本 / 证据 / 转介）
- `src/store.ts` — 追加式 reducer、规则校验、持久化与种子数据
- `src/App.tsx` — 证据台界面
